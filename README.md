# mellow｜ペットサロン・ペットホテル

犬と家族が安心して通えるペットサロン・ペットホテルのWebサイトです。「Home, Walk, and Us.」をコンセプトに、トリミングと宿泊それぞれのコースや利用の流れを確認し、予約案内へ進めるように構成しました。

[公開サイトを見る](https://coconattsu0723.github.io/mellow/)

## ページ構成

| ページ | 内容 |
| --- | --- |
| [Home](index.html) | サービス紹介、仕上がりギャラリー、よくある質問 |
| [About Us](about.html) | mellowのコンセプト |
| [Salon](salon.html) | トリミングのコースとご利用の流れ |
| [Hotel](hotel.html) | ペットホテルのコースとご利用の流れ |
| [Reservation](reservation.html) | ご予約案内とデモフォーム |
| [Reservation Complete](reservation-complete.html) | デモフォームの完了画面 |

予約フォームは画面遷移を確認するためのデモです。実際の予約受付には対応していないため、フォームの確認にはサンプル情報を使用してください。

## 使用技術

- HTML / CSS / JavaScript
- レスポンシブ対応、モバイルメニュー、FAQの開閉
- ファビコンとOGPの設定
- GitHub Pagesで公開

## ローカルで確認する

プロジェクトフォルダで以下を実行し、ブラウザで [http://localhost:8000/](http://localhost:8000/) を開きます。

```sh
python3 -m http.server 8000
```
